# Custom Currency 5e changelog

**Unreleased** lists changes that haven't shipped yet.

## Unreleased

### Added

- Added Patreon and permanent Discord invite badges to the README and Foundry listing.

## [14.1.7] - 2026-10-18

### Added

- This changelog, linked from the Foundry package page and the README.
- Custom currencies and hidden standard currencies now apply to Encounter sheets.

### Changed

- Supports Foundry V14 only for now. I'll add newer Foundry versions after testing them.
- Verified on Foundry VTT 14.369 with dnd5e 6.0.6.
- Updated the package description and author information.
- The module's website link now goes to its Foundry package page.

### Fixed

- Items priced in a custom currency show their price again on tooltips and chat cards with dnd5e 6.
- Converting coins no longer drops fractional amounts stored by other modules.
- Removed a Foundry V14 warning when physical currency links are cleared or repaired.
